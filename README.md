# Tragedy Looper — Digital Mastermind Companion

A single-file HTML/CSS/JavaScript web app (zero dependencies) implementing a
near-complete digital Mastermind companion for **Tragedy Looper: New
Tragedies** (WizKids 2022), with secondary support for the Z-Man Games
(2014) edition.

- **App:** [`tragedy-looper-advisor.html`](./tragedy-looper-advisor.html) — open directly in a browser, no build step.
- **Project handover / architecture notes:** [`TRAGEDY_LOOPER_HANDOVER.md`](./TRAGEDY_LOOPER_HANDOVER.md)

This project was restarted here from a prior session; see the handover doc
for the full data model, screen map, and list of known gaps / next steps.
